# AI Customer Support Chatbot

A practical AI-powered customer support chatbot built step by step with Python.

The project starts with a simple rule-based chatbot and gradually evolves into an AI-powered customer support system using APIs, Retrieval-Augmented Generation (RAG), AI agents, and workflow automation.

## 🎯 Project Goal

The goal of this project is to learn how to design and build a real-world customer support system that can:

- Understand customer questions
- Identify user intent
- Retrieve relevant information
- Generate useful responses
- Connect to external services through APIs
- Use knowledge bases and RAG
- Perform actions through AI agents
- Automate business workflows
